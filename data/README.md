# Data

The final hourly station-level feature dataset used for model training, testing, and feature-importance analyses is archived on Zenodo because of its file size.

**Dataset:** `combined_stations_era5_CA_2019_2024_features.csv`  
**DOI:** https://doi.org/10.5281/zenodo.22050395

After downloading, place the file at:

`data/combined_stations_era5_CA_2019_2024_features.csv`

The dataset can also be reproduced using the scripts in `R/preprocessing/`.
