# Figure 6: Fog Frequency Maps for December 2014 and August 2015 at 30-m resolution

This directory contains the workflow used to generate the 30-m fog-frequency maps presented in Figure 6.

The workflow is computationally intensive and was designed to be run on a high-performance computing (HPC) system / supercomputer.

## Required Input

## DEM

The terrain workflow begins with:

`DEM_CA_30m_albers_clean.tif`

This raster is generated by `R/preprocessing/02_prepare_DEM.R`, which downloads the SRTM 1 Arc-Second Global DEM (~30 m) using `elevatr` and an OpenTopography API key, then crops and reprojects it to NAD83 / California Albers (EPSG:3310) at 30-m resolution.

See `R/preprocessing/README.md` for DEM download and preparation instructions.

Place `DEM_CA_30m_albers_clean.tif` in this directory before running the scripts below.

## ERA5-Land

ERA5-Land hourly data are required for December 2014 and August 2015, with additional January 1, 2015 and September 1, 2015 data used as temporal padding due to the need to convert UTC to local time (-8 h in the winter; -7 h in the summer). Data should cover the whole of California and can be obtained from the Copernicus Climate Data Store (CDS).

The ERA5-Land inputs are separated into two groups:

- **Atmospheric/state variables:** 2-m temperature, 2-m dewpoint temperature, 10-m u- and v-wind components, skin temperature, and volumetric soil water (layer 1).
- **Accumulated flux variables:** surface net solar radiation, surface net thermal radiation, surface sensible heat flux, total evaporation, and total precipitation.

The scripts expect the downloaded NetCDF files to follow the directory and filename structure specified in the scripts (e.g., `era5_land_dec_2014_flux_CA_extracted/data_0.nc`).

## Terrain Processing

Run the scripts in order:

1. `01_terrain_base_30m.R`

   * Generates elevation, 30-m slope, northness, and eastness rasters.

2. `02_terrain_500m.R`

   * Generates 500-m mean slope, northness, eastness, and TPI rasters.

3. `03_terrain_1000m.R`

   * Generates 1000-m northness, eastness, and TPI rasters.

4. `04_terrain_5000m.R`

   * Generates the 5000-m TPI raster.

5. `05_distance_to_coast.R`

   * Generates the distance-to-coast raster aligned to the 30-m terrain grid.

6. `05_deaccumulate_era5.py`
   *Converts accumulated ERA5-Land flux variables to hourly values for December 2014 and August 2015.

Intermediate and output rasters are written to the working directory. Temporary raster files are written to `terra_tmp/` and do not need to be retained.
