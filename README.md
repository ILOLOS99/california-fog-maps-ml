# Code and data associated with the manuscript *“Mapping Fog Frequency Across California: A Machine Learning Approach.”*

## Repository Structure

- `R/` — R scripts for preprocessing, feature engineering, model development and evaluation, and feature-importance analyses.
- `Python/figures/` — Python scripts used to generate manuscript and supplementary figures.
- `figure_6/` — complete workflow for generating the 30-m fog-frequency maps for December 2014 and August 2015 presented in Figure 6.
- `data/` — input data, supporting datasets, and data-access documentation.

Detailed instructions and required inputs are provided in the README files within each directory.

## Computational Requirements

Model development and the high-resolution Figure 6 mapping workflow were performed on the Arizona State University Sol supercomputer.
